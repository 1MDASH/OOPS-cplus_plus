## Units Overview

### Unit I: Introduction to Object Oriented Programming
Focuses on fundamental OOP concepts including classes, objects, constructors, destructors, encapsulation, static members, and inline functions.

**Programs:**
1. Soil Sensor Monitoring System
2. Student Attendance Management System
3. Product Catalog Management System

### Unit II: Inheritance and Abstraction
Demonstrates inheritance hierarchies, abstract base classes, pure virtual functions, and runtime polymorphism.

**Programs:**
1. Employee Payroll System
2. Payment Gateway System
3. Vehicle Fleet Management System

### Unit III: Polymorphism
Explores different types of polymorphism including function overloading, operator overloading, and virtual functions.

**Programs:**
1. CAD Shape Drawing System
2. Complex Number Calculator
3. Input Validation Service

## Compilation

Each program can be compiled using g++:

```bash
g++ program_name.cpp -o program_name
./program_name
```

## OOP Concepts Demonstrated

- **Classes and Objects:** Creating user-defined data types
- **Encapsulation:** Data hiding using private/protected members
- **Inheritance:** Deriving new classes from existing ones
- **Polymorphism:** Function overloading, operator overloading, virtual functions
- **Abstraction:** Pure virtual functions and abstract base classes
- **Constructors & Destructors:** Object lifecycle management
- **Static Members:** Class-level data and functions
- **Smart Pointers:** Automatic memory management with unique_ptr
